# Subversive Software Homebrew Tap

Homebrew formulae for [Subversive Software](https://github.com/subversivesoftwareorg) tools.

## Usage

```bash
brew tap subversivesoftwareorg/tap
brew install conscience
```

| Formula | Description |
|---------|-------------|
| [conscience](Formula/conscience.rb) | Evaluate the impact of AI-assisted work |
